# 外部角色资产使用说明

把你**有合法授权**的模型和动画放进这个文件夹，游戏会自动加载、识别骨骼、重定向动画，并接入现有战斗系统（连招、蓄力劈棍、闪身无敌帧、定身法、受击、AI 等全部复用）。没有 `assets.json` 时自动使用程序化模型。

> 版权提醒：不要使用从《黑神话：悟空》游戏中解包/提取的模型或动画（Game Science 版权）。可用来源：自己购买的商业模型（CGTrader / ArtStation / Fab 等，按其许可证）、Sketchfab 上 **CC 许可且可下载** 的模型（注意 CC-BY 需署名、NC 不可商用）、Mixamo 动画（Adobe 账号下载，可用于项目）。

## 三步接入

1. 新建文件夹，例如 `public/assets/wukong/`，放入模型 `model.glb`（也支持 `.gltf` / `.fbx`，支持 Draco / Meshopt 压缩）。
2. 动画放到 `public/assets/wukong/anims/`。推荐 Mixamo：
   - 先把模型上传到 Mixamo 自动绑骨（如果模型本身没有骨骼）。
   - 每个动作下载设置：**FBX Binary、30 FPS、Without Skin（只要动画）**，跑步类勾选 **In Place**。
3. 复制 `assets.example.json` 为 `assets.json`，改好路径，刷新页面。

## 动作对照表

| 配置键 | 用途 | 缺失时 |
|---|---|---|
| idle / run / sprint | 待机、奔跑、疾跑（按速度自动混合） | sprint 缺失用 run 加速；idle 必需 |
| attack1~4 | 轻棍四连 | 依次回退到上一段 |
| charge / heavy | 蓄力 / 劈棍（heavy 带地面冲击事件） | heavy 回退 attack3 / attack1 |
| dodge | 闪身（自带无敌帧） | 仅保留位移与无敌 |
| hit / death / victory / drink / spell | 受击、死亡、胜利、饮葫芦、定身法 | 保留逻辑，动作不播放 |
| 敌人：slash1 / slash2 / leap / spin / hit / stagger / death / roar | 狼校卫招式 | 互相回退 |

## 每个动作的可选参数

（`//` 后面是说明，写进 assets.json 时要删掉，JSON 不支持注释）

```jsonc
"attack1": {
  "file": "/assets/wukong/anims/attack1.fbx",
  "clip": 0,              // 文件里第几段动画，或动画名字符串
  "speed": 1.0,           // 播放速度
  "trim": [0.1, 0.9],     // 截取片段（秒）
  "inPlace": true,        // 去掉水平位移（默认开，位移由游戏控制）
  "hit": [[0.3, 0.45, 1]],// 命中判定窗口 [开始秒, 结束秒, 伤害倍率]
  "combo": [0.4, 0.8],    // 可接下一段连招的窗口
  "cancel": 0.5,          // 之后可闪身/移动取消
  "events": [{ "t": 0.42, "type": "impact", "power": 0.5 }],
  "motion": [[0.1, 0.3, 3.0]]  // 前冲位移 [开始, 结束, 米/秒]
}
```

不填时，这些时间会按程序化动作的比例自动缩放到真实动画长度。

## 模型参数

- `height`：游戏内身高（米），模型自动缩放并落地。
- `rotationY`：模型默认朝向不是 +Z（面向镜头）时，填 180 或 ±90。
- `weapon`：
  - `{"type":"staff"}`：内置金箍棒挂到右手；`{"type":"sabre"}`：内置大刀。
  - `offset`（米）/ `rotation`（度）/ `slide`（握点沿棍身偏移，米），`hidden: true` 只保留命中判定不显示。
  - `{"type":"node","name":"Staff"}`：用模型自带的武器网格（非蒙皮）。
  - `bone`：默认 `RightHand`，可填实际骨骼名。

## 调试

- 打开「形神鉴赏」→ 左上角「资产诊断」：查看每根骨骼识别结果、缺失骨骼、每个动作加载情况。
- 同一面板的「武器挂点调校」可实时调整握持位置，调好后点复制，把 JSON 粘回 `assets.json` 的 `player` 里。
- 地址加 `#selftest`：用代码合成的测试角色（Mixamo 命名 A-Pose）+ 测试动画（UE 命名 T-Pose 厘米单位）跑一遍完整流程。

## 骨骼识别支持

自动识别 Mixamo（`mixamorig:*`）、Unreal（`pelvis / spine_01 / upperarm_l`）、Blender Rigify（`DEF-upper_arm.L`）、3ds Max Biped（`Bip01 L UpperArm`）、VRM（`J_Bip_L_UpperArm`）等常见命名。重定向在世界空间进行，并按静止姿势对齐骨骼方向，所以 **T-Pose 动画可以直接用到 A-Pose 模型上**，单位（厘米/米）和身高差异也会自动处理。手指骨骼在双方同名时（如都是 Mixamo）也会一并重定向。
